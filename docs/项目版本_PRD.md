# Git 总览 PRD（0.2）

## 背景与目标

为偶尔打开插件查看已有项目的用户提供 Git 地图：当前在哪条分支、停在哪次提交、是否有未提交修改、分支怎样分叉与合并。插件负责展示与传递上下文，Git 操作交给 Codex。

## 页面与层级

| 层级 | 默认内容 | 按需展开 |
|---|---|---|
| 首屏 | 当前分支、HEAD、提交时间、未提交数量、完整宽度的提交关系图 | 分支筛选、远程记录、定位当前 |
| 分支详情 | 完整名称、最新提交、相对当前位置各自独有的提交数 | 上游关联和工作树 |
| 提交详情 | 完整标题、时间、作者、改动文件数 | 完整原始信息，合并提交的父节点选择 |
| 未提交详情 | 暂存、未暂存、新文件和冲突文件分组 | 文件差异 |
| 文件差异 | 点击后读取真实差异 | 二进制/过大文件/缺失历史的状态 |
| Codex 请求 | 所选对象和可编辑意图 | 随请求发送的项目、分支、HEAD 上下文 |

## 主流程

打开当前项目 → 看当前位置与分支关系 → 点击分支/提交 → 必要时展开文件 → 需要帮助时点击「交给 Codex」并编辑请求 → 发送到当前聊天。

## 关键交互与状态

默认每个节点为一次提交，以本地分支为主，原始名称加中文辅助标注。详情关闭后保留选择与图位置。图与 Git 操作隔离，选择标签不会切换分支。

真实分叉/合并、多引用共用节点、未提交入口、特殊 Git 操作状态、无提交和浅克隆边界必须正确区分。历史分批读取，游标过期提示刷新。远程为本机已有记录，显示读取时间。

## 边界

不做页面截图、预览配置、自动中文翻译、Git 教学或直接 Git 写入。零配置打开，无需运行网页或调用 Agent 生成解释。保留旧版的 Git 历史和元数据。

## 验收

真实多分支仓库中的图、详情和差异正确；读取前后 Git 数据与项目文件一致；按需发送请求且上下文准确；窄面板、明暗主题和 200% 阅读可用。MCP Apps 测试宿主与实际 Codex 原生宿主分别验收。
